Use the screenshots in `docs/ui-reference/` as visual references for the Tessera redesign.

The implementation must prioritize the written specification over the screenshots.

Start with `00-overview-live-final.png` for the Vue d’ensemble Live state and `01-overview-replay-expanded-final.png` for the expanded time-travel state.

The key UX rule is:
State carries the verb. Time explains the change. Risk governs execution. Evidence closes the loop.

Live default: compact time rail only.
Replay expanded: same page, same structure, relit at T with baseline, comparison, event scrubber, and explicit return to Live.
